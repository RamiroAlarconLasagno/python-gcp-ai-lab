# Etapa 1.2: API async con FastAPI

## Objetivo

Exponer el cotizador puro por HTTP: `GET /health` y `POST /quotes` con modelos Pydantic v2, errores 422 claros y tests con cliente async, sin red ni credenciales.

**Terminado cuando:** se obtiene una cotización por HTTP y los datos inválidos se rechazan.

## Pasos hechos

1. Dependencias: `fastapi` y `uvicorn` (runtime) y `httpx` (dev), con `uv add`.
2. `app/main.py`:
   - `GET /health` devuelve `{"status": "ok"}`.
   - `POST /quotes` recibe `QuoteRequest`: campos obligatorios, números `Decimal` mayores que 0, y `zone` y `mode` como texto.
   - Llama a `calculate_quote` y devuelve `QuoteResponse` con todos los campos de `Quote`. Los `Decimal` viajan como texto JSON, sin perder precisión.
   - Un `ValueError` del cotizador se devuelve como 422 con su mensaje.
   - Endpoints `async def`, sin routers, servicios ni inyección de dependencias.
3. `tests/test_api.py`: 7 pruebas con `httpx.AsyncClient` + `ASGITransport`, marcadas con `@pytest.mark.anyio` y backend asyncio.
4. Prueba manual con `uvicorn --reload`: `/health`, `/quotes` y `/docs`.
5. `docs/design/complejidad.md` creado con la complejidad aceptada en la 1.1.

## Comandos usados

| Comando | Para qué |
|---|---|
| `uv add fastapi uvicorn` / `uv add --dev httpx` | Agregar dependencias; versiones fijadas en `uv.lock`. |
| `uv run uvicorn app.main:app --reload` | Levantar el servidor de desarrollo con la app `app` del módulo `app/main.py`, reiniciando al guardar cambios. |
| `curl http://127.0.0.1:8000/health` | Llamar a un endpoint desde la terminal. |
| `curl -X POST .../quotes -H "Content-Type: application/json" -d '{...}'` | Enviar una cotización como JSON. |
| `uv run pytest` / `uv run ruff check .` / `uv run mypy app` | Tests, lint y tipos. |

## Resultado observado

- `38 passed` (31 anteriores + 7 de la API); `ruff check` y `mypy app` en verde.
- Con el servidor levantado:
  - `GET /health` devuelve `{"status":"ok"}`.
  - `POST /quotes` con AMBA, 2,5 kg, 20×15×10, urgente devuelve total `"19200.00"` y 2 días.
  - Con zona `mars` devuelve HTTP 422.
  - `/docs` devuelve HTTP 200, y `openapi.json` lista `GET /health` y `POST /quotes`.

## Problemas y solución

| Problema | Solución |
|---|---|
| `@pytest.mark.anyio` corre cada test con asyncio y con trio, y trio no está instalado. | Fixture `anyio_backend` que devuelve `"asyncio"` en `tests/test_api.py`. |
| Los 422 tienen dos formas: Pydantic devuelve `detail` como lista de errores (`loc`, `type`, `msg`) y el cotizador como un texto. | Se acepta por ahora: cada test verifica la forma que le corresponde. Unificar el formato sería una decisión de diseño de la API. |
| Desde el entorno de Claude, `uv add` necesita `--system-certs` (TLS del sandbox). | Se usa solo en la línea de comandos de Claude, no en la configuración del proyecto. |
